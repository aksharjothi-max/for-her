# For Her 💕

All the websites I make for my girlfriend. Built with love, HTML/CSS/JS.

## Sites

- **Summer 2025** — [Live Demo](https://aksharjothi-max.github.io/for-her/summer-2025) — An interactive photo book of our summer together in Columbus, OH. Page-flipping with locked trivia puzzles on each page.

## How to Add a New Site

1. Create a folder at the root: `site-name/`
2. Put `index.html` inside it
3. Push to `main` — GitHub Pages handles the rest

## Tech Stack

- Pure HTML / CSS / JS — no frameworks
- GitHub Pages for hosting
- Custom design system with playful themes
